## 四、逐页代码审查结论

| 页面 | 本轮核对重点 | 当前结论 |
| --- | --- | --- |
| 主会话/导航 | 单一顶栏、任务卡片位置、路径引用、历史消息、状态来源 | 展示与状态 owner 分离；未增加消息/终态推断；保留已有会话和产物 |
| 输入与工具选择 | 窄列、自适应、盾牌、累计缓存与上下文区分、键盘选择 | 功能入口保留；选择器无 MCP/Skill 标签；底层执行方式不影响选择语义 |
| 预览/浏览器 | 标签与操作密度、固定按钮位置、实例保留、路径按需查看 | 一组控制跨并排/铺满复用；原生页与只读文档仍有各自内容边界 |
| 通用 | 显示语言、默认文件打开方式 | 复用原偏好 owner；语言双向切换功能已操作 |
| 外观 | 主题、强调色、密度、说明与焦点 | portal 主题变量共用；修正搜索导致整页外框；必要控件焦点保留 |
| Agent 行为 | 多行编辑、保存失败、响应语言 | R1 草稿/保存路径接入；不改变 Session Prompt 语义 |
| 执行环境 | Host OS、Windows Shell、PDF Python、项目环境 | 单一 Host OS 控制显示；PDF 输入复用草稿控件；Windows 字段仍由同一配置定义提供 |
| 工具权限 | 布尔/固定选项即时保存、摘要与面板一致 | 继续消费 runtimeEffectiveSettings；界面不扩大或替代授权 |
| 模型与服务 | 每个 profile 内保存、搜索入口、配置失败 | 保留已有逐 profile 保存和明确错误；普通搜索配置文本修正 R1 |
| 插件 | 一份清单、逐项详情、启停/失败、来源读取、翻译 | 保留原管理 owner 和实际加载状态；不同协议不形成第二份激活表 |
| 关于 | 实际版本/连接信息、更新界面 | 常驻噪声被收起，但诊断/更新仍可达；不把源码 SHA 当成运行相等门禁 |
| 项目/会话/导入弹层 | 取消、焦点与背景快捷键 | 已迁移共用 dialog；高影响行为继续沿用原用户决策入口 |

Apple 参考：[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)、[Offering help](https://developer.apple.com/design/human-interface-guidelines/offering-help)。据此保持操作邻近、降低重复视觉边界、让帮助按需出现；不声称获得 Apple 认证。
