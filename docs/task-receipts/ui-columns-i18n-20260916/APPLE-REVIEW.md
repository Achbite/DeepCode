# DeepCode：最终需求与 Apple 设计审查

日期：2026-09-16。范围：已授权的 DeepCode 前端布局、交互和本地化修订；沿用已有插件、设置和 Session 投影。当前分支 `session/document-skill-preview`，基线 `0369515`，保留已有工作区修改。

## 1. 当前最终布局

- 左侧：项目与对话导航；底部整行“设置”/“Setting”。导航与主工作区之间保留轻量边界。
- 主对话列：顶部对话标题和运行状态；中间消息；底部自适应输入框。添加和权限盾牌在左，上下文球、模型、发送在右。输入框下方居中显示“总缓存命中/Total cache hit”和百分比，取代快捷键提示。
- 右侧：收起预览时显示主页面的任务/产出卡片，产出标题没有数字。展开预览时，这两块隐藏；预览作为完整页面推挤主对话列。
- 预览列：标签在本列顶部，放大/还原紧邻唯一侧栏开关。主对话标题、运行状态随着主列收窄；不会混入预览列。按用户最新修订，并排展开时增加 1px 主题分隔线，连贯分开标题区与正文区；放大时不显示该线。
- 铺满：同一个 Reader 实例填满左侧导航以外的工作区；保留项目与对话导航，还原按钮留在右上同一位置。

用户随后确认的预览边界、标题留白、PNG 仅显示图片及“文件 / 浏览器”起始页修订，已实施并复核，见 [最新修订与证据](../preview-navigation-20260916/REVIEW.md)。该回执及截图取代此前放大时隐藏左导航的展示；下文原构建与运行记录保留为阶段证据。

完整历史需求已去除被后续指令取代的方案，汇总于 [U01—U26 完整对照](../ui-review-fixes-20260916/DELIVERY-CHECKLIST.md)；后续补充为 [C01—C16](TCR.md)。两表共同覆盖本次全部用户批注。

## 2. 官方设计依据

本次实际查阅 Apple 官方 Human Interface Guidelines，使用适用于桌面 WebView 的原则，沿用 DeepCode 现有组件和语义调色板。

| 官方参考 | 审查如何落实 |
| --- | --- |
| [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | 相关信息和操作归属同一列；用间距和表面层次分区；窗口变窄时按同一列宽重排 |
| [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) | 控件按任务分组；会话状态与预览操作分开；展开/还原固定在侧栏开关旁 |
| [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) | 共用系统字体栈，中文 PingFang SC、macOS 系统字体和 Windows Segoe UI；代码单独用等宽字体。使用清楚的字重和层级 |
| [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode) | 语义背景/表面/控件/文字随主题变化；灰黑层次替代纯黑，修复 portalled 设置的主题变量；内容文档和主题示意图保留原有内容色 |
| [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | 检查小字、对比度、键盘、焦点与 Esc；按钮取消蓝框后仍有表面反馈，选中状态增加勾选，避免只依赖颜色 |

Apple 的点值与 Web CSS 像素并不直接等价。本项目采用的 11–12px 辅助文字、13px 标签、14px 正文、16px 页标题、28–32px 常用桌面按钮，是结合当前应用密度的设计取值。上下文球内数字从 7px 增为 10px，球体尺寸不变。没有声称 Apple 规定这些 Web 尺寸或获得无障碍认证。

## 4. 本轮额外修复与理由

1. **选中状态的蓝框**：关闭设置的焦点框已去除，但主题和强调色选项仍有蓝框。现统一为背景/文字与勾选，保持可辨认的选中状态。
2. **文字对比度**：原浅色蓝/紫/绿强调色在白色表面上的比值约为 4.02/4.47/2.54，深色蓝色也偏低。调整语义颜色和按钮前景色，保持蓝/紫/绿含义。
3. **上下文数字**：原 7px 过小，改为 10px，无须扩大整个圆形按钮。
4. **工具菜单被消息按钮覆盖**：输入区弹层的父级层叠顺序低于消息浮动动作。提高输入区所属层级，保留布局和点击路径。
5. **读取插件后焦点丢失**：异步读取使触发按钮暂时禁用，自动捕获的前焦点不再是该按钮。插件页记录读取入口，关闭确认后恢复到实际触发按钮。
6. **多行编辑框被压窄**：grid 控件沿用了 flex 的靠右对齐而没有列宽约束。为多行控制区设置完整可用列宽，修复提示词编辑区域。
7. **英文长选项和服务页间距**：缩短权限选项的显示文本，保留完整说明；服务分区间增加间距。关于页状态和语言说明同步本地化。
